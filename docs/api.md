# Поисковый API

Единственный endpoint: GET /api/v1/search.

## Параметры

- city — обязательный город, после trim 1..100 символов. Москва/Сочи/СПб и варианты Санкт-Петербурга нормализуются; неизвестный город даёт пустую выдачу.
- budget — обязательная положительная сумма в рублях, до 99999999999999.99, максимум два знака после точки.
- rooms — повторяемый обязательный параметр; хотя бы одно значение. 0 = студия, 1/2/3 = точное число комнат, 4 = 4 и более. Например rooms=1&rooms=2. Повторы одного значения удаляются, список в ответе сортируется.

Пример: /api/v1/search?city=Сочи&budget=20000000&rooms=1&rooms=2.

Параметр area удалён и возвращает 422, как любой неизвестный параметр. Повтор city или budget — 422. Пустой выбор rooms, дроби, отрицательные значения, список через запятую и значения вне 0..4 — 422.

## Ответ 200

query содержит city, budget_rub (строка с двумя десятичными знаками) и rooms (массив 0..4). desired_area_m2 больше не возвращается. Остальные поля: generated_at (UTC ISO 8601), demo_mode, count, results, warnings.

results содержит все подходящие разные ЖК по возрастанию полной стоимости. В каждой карточке:
- complex: id, name, city, developer, district, housing_class, completion_status, completion_description, completion_source_url;
- match_type: lot;
- lot: id, rooms (реальное число комнат, включая 5 и более), area_m2, starting_price_rub, updated_at, source_url, building, is_demo;
- matched_area_m2: фактическая площадь выбранной квартиры;
- estimated_price_rub: опубликованная полная стартовая цена квартиры (название поля сохранено для совместимости карточки);
- price_source_url, price_observed_on, warnings.

Суммы и площади — десятичные строки с двумя знаками. В каждой карточке есть реальный лот; расчётные варианты без квартиры не возвращаются. При равенстве цены используется дата обновления, затем ID. count равен длине results; предупреждение INSUFFICIENT_MATCHES больше не используется.

## Ошибки

422 — некорректные параметры; 503 — недоступна БД; 500 — непредвиденная ошибка. Формат: {"error":{"code":"VALIDATION_ERROR","message":"Проверьте параметры поиска","fields":{"rooms":["Выберите комнаты"]}}}. Для 503/500 fields пуст. В ответ не включаются SQL и секреты.
