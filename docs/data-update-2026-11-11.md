## Методика и ограничения

Выполнен просмотр всех 15 проектов и альтернативных источников. Рабочий набор — выборка предложений, а не полная выгрузка рынка. Полные стартовые цены относятся к тем же строкам источника, что площадь и комнатность. Цена за м² не использована как цена квартиры. Студия = 0; NULL комнатности не преобразован в студию. Повторяющиеся объявления одной квартиры у разных агрегаторов не добавлялись. Количество найденных строк разных источников не суммируется как число уникальных квартир.

REALTY5: публичный GET /api/complex/{id}/lots отдаёт id, building, number, rooms, area, price, status. Выбраны только free с заполненными положительными ценой и площадью и известными rooms. updated_at взят из явно подписанного «Данные обновлены» time.dateTime на странице того же проекта; это дата данных прайса, не дата проверки и не HTTP Last-Modified. По Луиджи/Кислороду источник прямо пишет «по данным застройщика». Даты публикации статей и новостей не используются для лотов. В цену прайса могут входить скидки; индивидуальные условия оплаты в API отсутствуют, их необходимо уточнить перед сделкой.

МЕСТО: строки таблицы «Планировки и цены», дата «Обновлено 06.11.2026» непосредственно относится к таблице. Номер и корпус вместе образуют стабильный ключ. Комнатность сохранена по классификации источника. Не делалось предположений о скидке, ипотеке или рассрочке: условий у конкретных строк не указано.

Квадрум: в публичном Nuxt JSON каждой строки есть id, rooms, square, price, house_name, price_history. Использована последняя запись истории, у которой new_price равен текущему price. updated_at — настоящая дата изменения этой цены, поэтому неизменная старая цена остаётся старой. «Цены действительны на 11.11» без года не использовано. Это консервативная дата цены, а не доказательство повторной проверки наличия. Проверена прямая карточка Avant /offer/170800. Для Дефанса выбраны только строки с house_name=«Премиум». Квадрум показывает программу акции Avant с отдельным сроком; применимость акции к конкретным выбранным строкам не подтверждена. Стоимость ежемесячного ипотечного платежа не использована.

МИР КВАРТИР: для Острова, Отражения, Петровской Доминанты и одного Дефанса использованы датированные индивидуальные карточки из поискового индекса. Прямой запрос возвращает HTTP 403, web open — cache miss. Дата — явно указанное «Обновлено» в разделе информации об объявлении с годом; это не дата индексации. Наличие 11.11 не подтверждено прямым доступом. Эти строки отмечены в JSON findings; правила актуальности приложения основаны только на дате источника. Вторичные квартиры с ремонтом не эквивалентны черновым квартирам застройщика; состояние описано в замечаниях ниже.

ГРЦ: индивидуальная карточка Olivia ID 85854 проверена прямым HTTP. В исходном HTML «Обновлено: 10.11.2026» (поисковый кеш показывал 16.10). Цена 16 000 000, валюта RUB подтверждена schema.org priceCurrency, 41,6 м² и 1 комната. Вторичная продажа, один собственник, без обременений, черновая отделка.

- Остров: mskguru показывает относительное «18 часов назад», но абсолютного времени лота не найдено; эти карточки не импортированы. Не перенесены даты проверки стройки/надёжности Циан на квартиры.
- При проверке найдено, что REALTY5 маршрутизирует страницу по числовому ID и игнорирует текст slug. Ошибочные пробные URL №143 («Пегас Таунхаусы») и №231 («Набережный», Сириус) исключены; правильные Olivia=85, Светский лес=105. Названия и география сверены.
