# Поиск по комнатам и цене

Актуальные правила от 11.11.2026 заменяют подбор по желаемой площади.

1. Обязательные параметры: город, максимальный бюджет квартиры, один или несколько вариантов комнатности.
2. Варианты: 0 — студия; 1, 2, 3 — точное число комнат; 4 — четыре и больше. Выбранные варианты объединяются через ИЛИ.
3. Площадь не ограничивает выдачу; в карточке остаётся фактическая площадь квартиры.
4. Учитываются только активные лоты нужного города, в пределах бюджета, с датой источника от now − 30 суток до now включительно. now фиксируется на запрос.
5. Для каждого ЖК выбирается самая дешёвая квартира среди подходящих по комнатности. При равенстве цены — более свежее предложение, затем ID лота.
6. ЖК сортируются по возрастанию полной цены выбранной квартиры. При равенстве — более свежая дата, затем ID ЖК/лота. Сравнение денежных значений численное, не строковое.
7. Возвращаются все подходящие ЖК без лимита количества, по одной самой дешёвой квартире на ЖК. Бюджет и комнаты не расширяются автоматически.
8. Оценка по минимальной цене м² больше не используется: без площади и характеристик конкретной квартиры она не подтверждает соответствие комнатности.
9. Demo-лоты не входят в основной каталог; исторические записи сохраняются в базе, но исключаются по дате.

Проверки: объединение нескольких комнатностей, студии, 4+/5 комнат, точная граница бюджета, исключение других комнат, выбор дешёвого лота при иной площади, численный порядок 9 млн перед 10 млн, одна карточка на ЖК, валидация пустого выбора и удалённого параметра area, неизменность дат и точность денег.
